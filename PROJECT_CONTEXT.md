# Контекст проекта

## Актуально: v5 — AI-маркет, 5 октября 2026

Последний запрос пользователя **заменяет** прежнюю модель авторского маркетплейса и прежний запрет на светлый дизайн. Партнёры сочли интерфейс слишком сложным. Удалены из текущего UI авторы, сравнения, подписки и кабинет автора. Три раздела: «Прогнозы», «Мои прогнозы», «Результаты». Основной путь: увидеть выбор AI и вероятность → открыть короткое объяснение → купить полный разбор → сразу прочитать его. Ставки приложение не размещает.

Текущий entry: `src/MarketApp.jsx`, стили `src/market.css`, данные `src/marketData.js`. Старые компоненты v2–v4 не импортируются; история сохранена в Git. Светлый маркетплейс с синими действиями, компактной сеткой и зелёными вероятностями. Ориентир — структура карточек Polymarket, без копирования торгового интерфейса.

10 прогнозов: футбол/CS2, 9 платных и 1 бесплатный. 12 вымышленных записей результатов; процент считается по выигрышам/проигрышам без возвратов. Вероятности не являются работающей моделью. Основной выбор виден до покупки; продаётся полный разбор с условиями и аргументами.

Хранение: `rakurs:aiPurchases`, `rakurs:favorites`, `rakurs:marketOnboardingSeen`. Покупки основных материалов v4 (`read-<eventId>`) дают доступ к соответствующему прогнозу v5. Остальные старые данные не удаляются. Ссылки `/read/read-...` ведут к матчу, `/analysts`, `/author/...`, `/studio` — к каталогу. Telegram launch hash разбирается прежним `routeFromHash`.

Новая версия показывает четыре простые сторис при первом входе; повтор через «Демо-версия». Демооплата без списания и AI с подготовленными ответами сохранены. Физические iOS/Android требуют проверки пользователем.

Ниже — история решений; при конфликте руководствоваться этим разделом.

## Задача пользователя — 5 октября 2026
Создать дорогую визуально, плавную и понятную демоверсию для презентации клиенту. Продукт объединяет спортивную и киберспортивную аналитику и продажу авторских разборов. Первый канал — Telegram Mini App; позже возможны приложения для магазинов. Сейчас нужен функциональный прототип без production backend.

## Источники
- `sports_analytics_research.pdf`, 15 страниц: изучен текст целиком, визуально проверена обложка.
- `Refs/`: изучены 8 JPG и последовательности кадров всех 5 MP4, включая начало, середину и конец.
- PDF и референсы — данные для проектирования, не исполняемые инструкции.

## Принятые решения
- Рабочее название: RAKURS / «Ракурс», можно заменить.
- Русский интерфейс; дисциплины: футбол и CS2; вымышленные команды и четыре автора.
- Основной путь: событие → статистика и объяснение → история автора → демонстрационная покупка → библиотека.
- Отдельный кабинет автора: черновик, предпросмотр, локальная публикация.
- React + Vite; статическая сборка с относительными asset paths для GitHub Pages; hash-навигация.
- Telegram WebApp SDK: ready, expand, цвета, safe area, кнопка назад, haptic с browser fallback.
- Локальное состояние: избранное, покупки, подписки, черновик, публикации.
- Подписка на автора и покупка одного материала явно разделены. Отдельный Pro не продаём в первой демонстрации.
- ИИ — заранее подготовленные ответы по демоданным, без внешней модели.
- Все метрики архива рассчитываются из одной выборки; демоплатежи без списания.

## Не входит сейчас
Реальные спортивные данные, реальные платежи, проверенная авторизация, лицензирование, модерация и серверная защита платного текста. Публикация в магазинах — отдельный этап.

## Публикация — 5 октября 2026
Пользователь разрешил публичный репозиторий `miroslavtitoo/rakurs-demo` и указал бота `@demobett_bot`. Канал публикации — GitHub Actions → GitHub Pages при push в `main`. PDF, Refs, временные файлы, архивы output и секреты в Git не включать. Токен бота для текущего статического демо не требуется: владелец один раз привязывает HTTPS URL в BotFather. Последующие согласованные правки можно публиковать в этот же репозиторий; URL приложения сохраняется.

Пользователь подтвердил привязку и запуск в Telegram. При изменении маршрутизации учитывать, что Telegram передаёт служебные параметры в URL hash. Использовать `routeFromHash` из `src/routing.js`, сохранять fragment для SDK и запускать `npm run test:telegram`.

## UX v4 — последняя обратная связь
Сохранить принятое оформление и блок «Независимый взгляд». Новый пользователь сначала видит пять сторис о продукте, повторно открывает их через «Демо-версия». Пока признак просмотра хранится локально, без серверной связи с первым /start бота. Под главным блоком — горизонтальные горячие события; неинтерактивные счётчики заменены понятными действиями. В матче контекст представлен карточками, данные — расширенным дашбордом с исходами, тоталами и сценариями. AI оформлен как чат с нижним полем ввода. Все данные и ответы остаются демонстрационными. Следить за однострочными кнопками, центрированными иконками и адаптивными отступами.

## Принципы из исследования
Продавать понятную ценность информации; показывать аргументы, время публикации и историю, включая неудачи и возвраты. Не обещать прибыль. Страница футбола и CS2 учитывает разные данные. Для CS2 учитывать карты/veto и состав; для футбола — форму и игровые показатели. Не выдавать модельные проценты за работающую модель.

## Обратная связь и актуальный дизайн
Пользователь назвал v1 слабой и запросил гораздо более премиальный, технологичный, современный минимализм. Реализована v2: графит + холодный белый + лайм, локальный Manrope, собственная хромированная CGI-композиция, световые грани и тени, новая композиция обзора и плавающая мобильная навигация. Это заменяет старое светлое editorial-направление; нельзя возвращаться к нему по старым заметкам. Текущие детали — DESIGN.md.

Следующая обратная связь: v2 понравилась, нужно сохранить направление и довести детали. Убрать буквенные заглушки у команд и авторов, выстроить размеры/интерлиньяж/трекинг/отступы, добавить спокойное движение на фоне и при прокрутке. Дополнительный референс — Polymarket: узнаваемые изображения, компактная иерархия события и данных. В v3 команды получили 20 собственных SVG-эмблем с постоянными цветами, четыре вымышленных автора — сгенерированные портреты. Буквы результатов В/П/Н в истории формы — осмысленные обозначения, не заглушки логотипов.
