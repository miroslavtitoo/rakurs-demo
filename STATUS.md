## Исправление первого запуска из Telegram — 5 октября 2026

Пользователь сообщил: при нажатии «Открыть» сначала показывался экран «Такого экрана нет», затем кнопка «В обзор» работала. Воспроизведено в браузере с launch hash `#tgWebAppData=...&tgWebAppVersion=...`: App использовал весь fragment как route.

`src/routing.js` отделяет путь приложения от launch-параметров, использован при инициализации, hashchange и navigate. Запуск без пути ведёт сразу в обзор; deep links сохраняются. Сам hash не переписывается, чтобы Telegram SDK сохранил initData. Настоящие неизвестные маршруты продолжают показывать 404.

Добавлены три регрессионных unit-теста (всего 9 в npm test) и `npm run test:telegram`: пять форм launch hash с настоящим SDK и синтетическими данными, reload, переход в аналитиков, Back, отсутствие page errors. Старый SDK mock начинал с `#/match/...`, поэтому не покрывал первоначальный Telegram hash; новый тест закрывает этот пробел.
