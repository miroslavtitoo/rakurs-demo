## v8.2 — Telegram fullscreen и первый запуск, 14 ноября 2026

По прямой правке пользователя Telegram инициализируется с `expand()` как fallback, `disableVerticalSwipes()` (Bot API 7.7+) и `requestFullscreen()` (8.0+). Повторная активация восстанавливает режим; уже включённый fullscreen повторно не запрашивается. Обрабатывается `fullscreenFailed/UNSUPPORTED`; старые клиенты остаются в поддерживаемом развёрнутом режиме. Учитываются safeAreaInset + contentSafeAreaInset по всем сторонам, обновления fullscreen/viewport и пустой initData при Telegram keyboard launch. Обычный браузер не вызывает нативные методы.

Автоматические сторис открываются только до первого закрытия/пропуска. Маркер `rakurs:pdfOnboardingSeen` проверяется строго как boolean true и записывается синхронно при закрытии. Вход по номеру больше не запускает сторис повторно; отложенный заказ и первый подарок сохраняются. Повторные обычные запуски открывают каталог; смысловые deep links остаются рабочими. Ручной повтор через «Демо · 18+» сохранён. Учёт первого посещения локальный для этого браузера/WebView; очистка данных или новое устройство начинают знакомство заново.

Сторис получили непрозрачный верхний слой выше интерфейса/уведомлений и безопасные отступы Telegram, включая небольшие экраны. На 320×568 исправлено наложение иллюстрации на заголовок при системных отступах.
