# Diverge — спортивная аналитика v9

Мобильное приложение по дизайнам «Бет.pdf»: обязательные вводные истории, Telegram-вход с альтернативой по телефону, гостевой каталог, анализ матчей, пакеты и подписка, профиль, новости и ежедневные монеты. Основная платформа — Telegram Mini Apps.

Это статический UX-прототип. По прямой просьбе владельца служебные пометки удалены из интерфейса. Внутри остаются вымышленные события/источники, подготовленные ответы и локальные операции; настоящие платежи, SMS, AI-запросы и Telegram-напоминания не выполняются. Доступ и баланс не защищены сервером.

## Запуск и проверка

Node.js 22.12+ и Microsoft Edge для Playwright:

```powershell
npm ci
npm run dev
```

Адрес http://localhost:5173/ . С запущенным dev server:

```powershell
npm test
npm run test:e2e
npm run test:design
npm run test:mobile
npm run test:telegram
npm run test:telegram-window
npm run build
node scripts/check-build.mjs
```

`test:e2e` и `test:experience` запускают `scripts/check-rewards.mjs`: обязательное знакомство, семь ежедневных наград, оба способа обмена монет, купон, Telegram-профиль, гостевые ограничения, покупки/подписка, история/факторы/чат и 35 сочетаний страниц с размерами 320×568, 390×844, 430×932, 768×1024, 1440×1000. `DEMO_URL` меняет адрес, в том числе на публичный. Снимки — `tmp/rewards-v9/`.

`test:mobile` проверяет анимационные сцены и последовательность текста, тап/свайп, центрирование/точки/колесо слайдеров, поиск и 55 мобильных композиций. `test:design` — клавиатуру, фокус и reduced motion. Telegram-проверки используют настоящий SDK и синтетические launch/native bridge: это не проверка физического iOS/Android Telegram. `check-build.mjs` сам запускает production-сборку в подпапке `/rakurs-demo/` и проверяет ресурсы/покупку.

## Истории и награды

Первый визит в конкретном браузере/WebView открывает четыре вводные истории поверх всего приложения. Пропуск и закрытие отключены; будущий сегмент недоступен до прохождения предыдущих. После завершения сохраняется `rakurs:pdfOnboardingSeen`; следующие запуски ведут в каталог. Крайняя правая история «О приложении» повторяет знакомство и не имеет обводки. Информационные истории получают градиентную обводку до открытия; новые публикации добавлять в начало `NEWS_ITEMS` в `RewardsUI.jsx` с новым стабильным id. Пока это контент из репозитория, серверной загрузки нет.

Окно монет автоматически появляется один раз за календарные сутки Europe/Moscow после онбординга/закрытия других диалогов. Закрытие окна учитывается как показ, но награду можно получить позже через баланс слева от аватара. Награды: 10, 15, 15, 20, 20, 25, 25 — всего 130 за семь дней подряд. Повторное получение в те же сутки запрещено. Пропуск сбрасывает серию, накопленный баланс сохраняется. После седьмого дня начинается следующий цикл.

130 монет обмениваются на один полный прогноз либо одноразовый купон 30% на пакет от двух прогнозов. Купоны не складываются; цена округляется до целого рубля. Купон расходуется только при оформлении подходящего пакета. В заказе одного матча есть выбор рублей, 130 монет или ранее полученного доступа. Старые покупки/избранное/кредиты сохраняются. Мгновенный подарок двух анализов новым входам больше не выдаётся.

## Вход, доступ и цены

Главное действие — «Продолжить с Telegram». Внутри Mini App профиль читается из SDK и сохраняется локально; в обычном браузере открывается существующий бот. Это ещё не серверная регистрация и не проверка подлинности initData. Номер телефона остаётся альтернативным локальным входом: любой номер без SMS, сохраняется только суффикс. Отложенный заказ продолжается после входа. Гость не может открыть прогноз или приобрести его.

Полный анализ 199 ₽, месяц всех событий 1000 ₽. Пакеты исходов 3/5/10 за 29/129/259 ₽; пакеты полного анализа 1/3/5 за 199/549/899 ₽. Исходы не открывают факторы и чат. Баланс/карты/платежи имитируются локально; реальные реквизиты, документы и токены не запрашиваются. Вероятности и факторы согласованы до 100%, неподтверждённые социальные гипотезы не меняют расчёт.

Ключи состояния с префиксом `rakurs:`: `pdfOnboardingSeen`, `rewardsWallet`, `readNews`, `demoUser`, `analysisCredits`, `outcomeCredits`, `outcomePurchases`, `demoBalance`, `demoTransactions`, `demoCards`, `generalChat`. Технические имена старых ключей сохранены для совместимости. Покупки `aiPurchases`, подписка `aiSubscription`, `favorites`, `eventChat:<id>` и meaningful legacy-ссылки продолжают работать. Очистка данных или другое устройство создают новое локальное состояние.

## Telegram и публикация

Приложение: https://miroslavtitoo.github.io/rakurs-demo/ . Бот: https://t.me/demobett_bot . Репозиторий: https://github.com/miroslavtitoo/rakurs-demo .

На поддерживаемых клиентах запрашивается `requestFullscreen()` (API 8.0+) и `disableVerticalSwipes()` (7.7+); `expand()` остаётся fallback. Safe areas учитывают системные и контентные отступы. Старые клиенты работают в поддерживаемом развёрнутом режиме. Источник: [Telegram Mini Apps API](https://core.telegram.org/bots/webapps#initializing-mini-apps). Физические устройства требуют отдельной проверки.

Push в `main` запускает GitHub Actions: `npm ci`, `npm test`, `npm run build`, публикация всего `dist` в Pages. Используются уникальное имя artifact для каждого run/attempt и ожидание его регистрации. Маршруты — hash; при другом хостинге нужно раздавать assets/fonts/images вместе с index.html и учитывать base path Vite. Бот-токен для публикации не нужен, адрес в BotFather менять не требуется; после деплоя переоткрыть Mini App.

v8.2 опубликована успешно: [Actions 43583807744](https://github.com/miroslavtitoo/rakurs-demo/actions/runs/43583807744), commit 11e4801 (feature 87336c4). Публикация v9 будет отмечена в STATUS.md после проверки публичной версии.

## Структура

`AssistantApp.jsx` — состояние/доступ/маршруты; `PdfScreens.jsx` — экраны; `AssistantUI.jsx` — общие диалоги; `RewardsUI.jsx` — истории и награды; `rewards.js` — арифметика кошелька; `presentation.js` — отображение старых служебных текстов без изменения хранения; `StoryArt.jsx`/`EventSlider.jsx` — движение и слайдеры. Слои стилей заканчиваются `pdfDesign.css`, `mobilePolish.css`, `rewards.css`.

Исходный PDF и `Refs/` сохранены. Локальные Oswald/Golos Text визуально приближают макет: в исходном PDF файлы гарнитуры отсутствуют. Контекст продолжения — `AGENTS.md`, `PROJECT_CONTEXT.md`, `DESIGN.md`, `STATUS.md`.
