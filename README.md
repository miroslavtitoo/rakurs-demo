# Ракурс — демонстрационное приложение v3

Стильный интерактивный прототип спортивной и киберспортивной аналитики, подготовленный для Telegram Mini App. Рабочее название можно заменить. Текущий дизайн: графит, хром, лаймовый акцент, локальный Manrope и плавающая мобильная навигация. Визуальная система построена по фотографиям и видео из `Refs/`, продуктовый сценарий — по исследованию пользователя.

В v3 добавлены собственные SVG-эмблемы всех команд, локальные портреты четырёх вымышленных аналитиков, уточнённая типографическая иерархия, новые мобильные карточки, мягкий фоновый свет и параллакс. Дополнительный визуальный ориентир — иерархия событий и изображений Polymarket. Промпты портретов: `docs/IMAGE_PROMPTS_PORTRAITS.txt`.

## Посмотреть локально

На этом компьютере во время разработки: **http://localhost:5173/**.

Для повторного запуска откройте папку проекта в терминале:

```powershell
npm install
npm run dev
```

Или запустите `START-DEMO.cmd`. Нужен Node.js 22.12+ (либо современная совместимая версия; проверено с Node 25). После закрытия сервера локальный адрес перестанет работать.

## Что работает

- 12 условных событий: футбол и CS2, даты, поиск, сортировка, избранное.
- Страница матча: контекст, разные статистические показатели по дисциплинам, история коэффициента, авторские разборы.
- Подготовленные объяснения «Ракурс AI» с маркировкой демоданных и источников.
- 4 вымышленных аналитика, сравнение двух авторов, профиль, график, периоды 30/90/365 дней, архив побед, поражений и возвратов.
- 24 авторских материала, бесплатный контент, отдельная покупка и подписка на автора.
- Демопокупка без списания; купленный доступ, подписки и избранное сохраняются после перезагрузки.
- Библиотека с управлением подписками. Отмена подписки сохраняет отдельно купленные материалы.
- Кабинет автора: автосохранение черновика, проверка полей, предпросмотр, публикация в локальный каталог.
- Адаптивные экраны, плавные переходы, нижняя навигация на телефоне, поддержка reduced motion, клавиатуры и фокуса в диалогах.
- Telegram SDK: ready/expand, цвета оболочки, безопасные отступы, нативная кнопка назад, haptic. Вне Telegram работает как веб-приложение.

## Сборка

```powershell
npm ci
npm test
npm run build
npm run preview
```

Результат — папка `dist/`. Можно разместить её на статическом HTTPS-хостинге. Относительные пути ресурсов и hash-навигация позволяют запускать приложение в подпапке GitHub Pages без серверных rewrite-правил. Шрифты и иллюстрация включены в сборку; извне загружается только Telegram SDK.

## GitHub Pages → Telegram

GitHub хранит исходники, **GitHub Pages публикует приложение**, BotFather привязывает опубликованный HTTPS-адрес к боту. Загружать сам код в BotFather не нужно.

1. Создайте репозиторий GitHub. Для простого бесплатного демо удобно использовать публичный репозиторий.
2. Загрузите исходный проект в ветку `main`, включая `package.json`, `package-lock.json`, `index.html`, `vite.config.js`, `src/`, `public/` и `.github/workflows/deploy.yml`. Не загружайте `node_modules`, `tmp`, PDF и `Refs` — они исключены в `.gitignore`. При ручной загрузке через браузер это исключение автоматически не применяется.
3. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. В **Actions** запустите workflow **Deploy demo to GitHub Pages** через **Run workflow**, либо отправьте изменение в `main`. Дождитесь успешного завершения.
5. Откройте адрес, который покажет Pages, обычно `https://USERNAME.github.io/REPOSITORY/`. Проверьте его сначала в обычном браузере.
6. Откройте [BotFather](https://t.me/BotFather), создайте бота через `/newbot` или выберите существующего.
7. Для кнопки меню: `/setmenubutton` → выбрать бота → указать HTTPS-адрес → название кнопки, например «Открыть Ракурс».
8. Для кнопки запуска в профиле дополнительно настройте Main Mini App через `/mybots` → бот → Bot Settings → Configure Mini App. Укажите тот же адрес. Названия пунктов могут зависеть от языка интерфейса.
9. Откройте бота на телефоне и нажмите кнопку приложения. Пройдите сценарий ниже.

Официальные источники: [GitHub Pages: custom workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [Telegram Mini Apps](https://core.telegram.org/bots/webapps#launching-mini-apps-from-the-menu-button).

Токен бота для статического демо не требуется. Его не нужно вставлять в исходники или отправлять в чат. Реальная Telegram-авторизация в этой версии не реализована: данные SDK не используются для защиты платного контента.

## Сценарий презентации — около 5 минут

1. Главная: показать стиль, выбрать CS2 и добавить матч Northern Foxes — Metro Five в избранное.
2. Открыть матч: показать контекст, график, перейти к статистике карт.
3. «Объяснить матч»: выбрать вопрос про риск veto и показать источник демоданных.
4. Аналитики: выбрать Марка и Льва для сравнения, открыть профиль Марка и архив с неудачами и возвратами.
5. Открыть материал «Northern Foxes: что решит выбор карт», выполнить бесплатную демопокупку, прочитать полный текст.
6. Перейти в «Мои материалы», перезагрузить страницу — доступ останется.
7. Кабинет автора: заполнить материал, показать предпросмотр и публикацию в локальный каталог.

Перед чистым показом удобно открыть приватное окно браузера. Для полного сброса текущего устройства удалите ключи `rakurs:*` из localStorage через инструменты браузера. Публикации и черновики также удалятся.

## Проверка

`npm test` проверяет связи событий/авторов/материалов, согласованность графика и ROI с архивом, правила расчёта и права демодоступа.

`npm run test:e2e` запускает Playwright и требует работающий сервер на 5173 и установленный Microsoft Edge. Для другого Chromium-браузера задайте `PLAYWRIGHT_CHANNEL=chrome`; адрес сервера можно изменить через `DEMO_URL`. Скрипт проверяет покупку, подписку, отмену, архив, публикацию, восстановление состояния, 8 маршрутов на 5 ширинах и имитацию Telegram WebApp. Скриншоты сохраняются в `tmp/screenshots`.

Реальный запуск внутри iOS/Android Telegram требует публикации и привязки к вашему боту. Автоматическая имитация SDK не заменяет эту проверку.

## Контекст для продолжения

- `AGENTS.md` — правила работы в проекте.
- `PROJECT_CONTEXT.md` — цель, сценарии, решения и границы.
- `DESIGN.md` — интерпретация всех визуальных референсов.
- `STATUS.md` — текущая готовность, проверки и дальнейшие шаги.
- `docs/IMAGE_PROMPT_V2.txt` — точный prompt новой CGI-иллюстрации; создана встроенным image_gen.
- `docs/assets/signal-source.png` — оригинал текущей иллюстрации; `public/images/signal.webp` — оптимизированный файл приложения.

## Граница демо

Даты зафиксированы на 5 октября 2026. Команды, аналитики, результаты и цены вымышлены. ИИ использует готовые ответы, а не подключённую модель. Данные пользователя хранятся только в localStorage этого браузера. Платный текст находится во frontend, поэтому здесь демонстрируется UX доступа, а не реальная защита контента.

Production потребует серверной авторизации, лицензированных данных, backend-доступов, платёжного потока, модерации и проверки требований каналов распространения. В App Store эту папку нельзя загрузить как готовое нативное приложение; это отдельный следующий этап.
