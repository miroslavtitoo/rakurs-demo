# Diverge — демо спортивной AI-аналитики v8

Дизайн и сценарии обновлены по семи листам `Бет.pdf`. Четыре сторис, локальный вход по любому номеру, гостевой каталог, поиск и фильтры, открытие прогноза, факторы, чаты, пакеты и подписка, профиль и демоплатежи. Все данные, оплаты и ответы вымышлены.

## Мобильная редакция v8.1

Живые сцены и последовательное появление текста в сторис, перелистывание нажатием по краям/свайпом, повтор после демовхода. Центрированные слайдеры TOP LIVE/PRE-MATCH с точками; единая мобильная сетка каталога, поиска, профиля, оплаты и аналитики. Ввод общего чата остаётся над нижним меню на коротких экранах. Финальный слой стилей — `src/mobilePolish.css`; новые компоненты — `StoryArt.jsx`, `EventSlider.jsx`.

`npm run test:mobile` проверяет анимационные сцены, тап/свайп, центрирование/точки/колесо слайдера, поиск и 35 сочетаний страниц с размерами 320×568, 360×640, 390×844, 430×932, 768×1024 плюс 20 композиций сторис. Снимки: `tmp/polish-v81/`. Остальные команды и схема публикации прежние.

## Запуск и актуальные проверки

Требуется Node.js 22+; `npm ci`, затем `npm run dev`. Локальный адрес: http://localhost:5173/ .

- `npm test` — согласованность данных, вероятностей и legacy-ссылок.
- `npm run test:e2e` (также `test:experience`) — актуальные PDF-сценарии и 28 комбинаций адаптива. Нужен запущенный dev server и Playwright с Microsoft Edge; адрес меняется через `DEMO_URL`.
- `npm run test:design` — анимация, пауза сторис, клавиатура, фокус и reduced motion.
- `npm run test:telegram` — launch hash, настоящий SDK с синтетическими launch-параметрами, reload и Back.
- `npm run build`, затем `node scripts/check-build.mjs` — production, локальные ресурсы и запуск в подпапке `/rakurs-demo/`.

Для публикации используется существующий GitHub Actions workflow: push в `main` выполняет `npm ci`, `npm test`, `npm run build` и выкладывает `dist` в GitHub Pages. Diverge v8.1 опубликована 10 ноября 2026: commit `fe30a24`, [успешный workflow](https://github.com/miroslavtitoo/rakurs-demo/actions/runs/42844021418). Публичные E2E, мобильные сценарии и Telegram launch-проверки прошли. URL и бот сохраняются; токены не нужны. Статический хостинг должен раздавать содержимое dist целиком, включая assets, fonts и images; маршруты используют hash.

## Доступ и демосостояние

Гость видит каталог, но прогноз открывается после демовхода. Введите любой номер, SMS не требуется; на сервер ничего не отправляется, локально сохраняется только суффикс номера. Первый вход даёт 2 анализа один раз на браузер. Старые покупки/избранное не удаляются. Это визуальная имитация доступа, не серверная авторизация или защита платного текста.

Полный анализ 199 ₽, месяц всех событий 1000 ₽. Пакеты исходов 3/5/10 за 29/129/259 ₽; полный анализ 1/3/5 за 199/549/899 ₽ — адаптированные демотарифы. Пакеты исходов не открывают факторы и чат. Баланс и карты виртуальные; реальные реквизиты и документы не запрашиваются. Внешние сообщения не отправляются.

Новые ключи localStorage: `rakurs:pdfOnboardingSeen`, `demoUser`, `demoGiftClaimed`, `analysisCredits`, `outcomeCredits`, `outcomePurchases`, `demoBalance`, `demoTransactions`, `demoCards`, `generalChat` (все с префиксом rakurs:). Старые ключи покупок, подписки, избранного и чатов сохранены.

Исходники экранов: AssistantApp.jsx, PdfScreens.jsx, AssistantUI.jsx; финальные стили pdfDesign.css. Извлечённые иллюстрации: public/images/diverge. PDF и Refs не изменены. Файлы исходной гарнитуры в PDF отсутствуют; локальные Oswald и Golos Text приближают макет. Мобильный Telegram на физических устройствах отдельно не проверен.

## Новая версия

Визуальная редакция v7: крупные цифры и заголовки, анимированный AI-объект, контрастная покупка, короткие выводы. Источники, пояснения и расчёты раскрываются в отдельных окнах. `test:design` проверяет движение, reduced motion и мобильные диалоги.

- 19 вымышленных событий: футбол, киберспорт, теннис, баскетбол, хоккей.
- Фильтры спорта и статуса: все, ближайшие, сейчас идут, завершённые. Поиск команд, игроков и турниров; избранное.
- Текущие и финальные счета — фиксированный демоснимок. Предматчевые оценки зафиксированы отдельно, задним числом не меняются.
- До покупки видны только событие и описание. Вероятности, факторы и чат закрыты в интерфейсе.
- Демопокупка одного прогноза за 199 ₽ без списания.
- Подписка за 1 000 ₽ на календарный месяц, все события и чаты. Автопродления нет. Завершение демоподписки сразу отнимает её доступ; отдельные покупки остаются.
- Дашборд: вероятности исходов, факторы, вклад в п.п., выборки, даты и образцы источников. Для футбола предусмотрена ничья. Сумма равна 100%.
- Чат по каждому событию с темами и вводом своей гипотезы. Истории сохраняются раздельно.
- Четыре сторис при первом входе, повтор через «Демо-версия»; таймер, пауза, свайп, reduced motion.
- Telegram SDK: ready/expand, safe area, цвета и нативный BackButton.

## Данные и состояние

Локальные ключи: `rakurs:aiPurchases`, `rakurs:favorites`, `rakurs:aiSubscription`, `rakurs:eventChat:<id>`, `rakurs:assistantOnboardingSeen`. История доступна на этом устройстве. Старые основные покупки v4 (`read-<id>`) и покупки v5 сохраняют доступ. `/results` ведёт к завершённым событиям, старые ссылки материалов — к событиям.

Текущий entry — `src/AssistantApp.jsx`. Общие диалоги/сторис в `AssistantUI.jsx`, данные и модель деморасчёта в `assistantData.js`, стили `assistantDesign.css` поверх `assistant.css` и `market.css`, общий декоративный компонент `AIOrb.jsx`. Исторические v2–v5 приложения сохранены, но не являются текущим entry.

## Сценарий презентации

1. Выбрать спорт, посмотреть текущий счёт или ближайший матч.
2. Открыть событие и купить анализ без списания.
3. Нажать «Почему 65%?» и показать арифметику факторов.
4. Раскрыть фактор: источник, дата, выборка, вклад.
5. Открыть чат, спросить о составе или ввести «Если по моим данным…».
6. Подключить подписку и открыть другой матч без покупки.
7. Завершить демоподписку: отдельно купленный прогноз останется.

## Границы демонстрации

Снимок зафиксирован на 8 октября 2026. Все участники, результаты, данные, источники и вероятности вымышлены. Поправки заданы для объяснения интерфейса, не получены обученной моделью. Подготовленные ответы чата не являются подключённым свободным AI. Ссылки и соцсети не открываются, реальные травмы и события не проверяются.

Публичный праздник или пост из соцсети сами по себе не доказывают нарушение тренировок/употребление алкоголя; неподтверждённый фактор имеет нулевой вклад. Гипотезы из чата не меняют официальный демопрогноз.

Оплата имитируется. Платные данные находятся во frontend: это UX-прототип, а не серверная защита. Production потребует лицензированных источников, проверяемой модели и калибровки, backend-проверки доступа и платежей. Браузерные проверки не заменяют проверку на физических iOS/Android Telegram.

Контекст продолжения: `AGENTS.md`, `PROJECT_CONTEXT.md`, `DESIGN.md`, `STATUS.md`. PDF и `Refs/` сохранены без изменений и исключены из Git.
