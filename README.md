# Ракурс AI — демомаркет прогнозов v5

Простой путь: выбрать AI-прогноз → понять аргументы → открыть полный разбор → вернуться к нему в «Моих прогнозах».

## Опубликованное приложение

- Telegram: https://t.me/demobett_bot
- Приложение: https://miroslavtitoo.github.io/rakurs-demo/
- Репозиторий: https://github.com/miroslavtitoo/rakurs-demo

Каждый push в `main` запускает тесты, сборку и GitHub Pages. URL остаётся прежним. Владелец уже привязал его через BotFather; для новых редакций менять бота не нужно. Для обновления переоткройте Mini App.

## Что работает

- Каталог из 10 вымышленных прогнозов на футбол и CS2. Поиск, спорт, даты, сортировка, избранное.
- В карточке сразу видны выбор AI, вероятность, условный коэффициент и цена.
- «Почему?» открывает короткое объяснение: аргументы, смысл вероятности и риск.
- Демопокупка за условные 390 ₽ без списания. Один прогноз можно открыть бесплатно.
- Полный разбор: условия прогноза, аргументы и детали перед матчем. После покупки сразу открывается для чтения.
- «Мои прогнозы»: купленные/бесплатные разборы и избранное, сохранение после перезагрузки.
- «Результаты»: 12 вымышленных записей; успешные, неуспешные и возвраты. Процент считается из показанного списка, возвраты исключаются.
- Четыре сторис при первом входе; повтор через «Демо-версия». Свайпы, таймер, пауза, ручное переключение. При reduced motion автопереход отключён.
- Telegram ready/expand, цвета, safe area, нативный BackButton. В обычном браузере тоже работает.

Авторы, сравнения, подписки и кабинет автора убраны по новой продуктовой концепции. Исход виден до покупки; приобретается полный разбор. Приложение не принимает ставки.

## Запуск и проверки

Нужен Node.js 22.12+.

```powershell
npm ci
npm run dev
```

Локально: http://localhost:5173/ . Для Windows есть `START-DEMO.cmd`.

```powershell
npm test
npm run test:e2e
npm run test:telegram
npm run build
node scripts/check-build.mjs
```

- `npm test`: данные, результаты, права доступа, перенос ссылок/покупок, Telegram hash.
- `test:e2e` и `test:experience`: текущий `scripts/check-market.mjs`. Покупка, бесплатный доступ, объяснение AI, сохранение, результаты, адаптивность, старые ссылки, сторис и Telegram mock. Нужен dev server и Microsoft Edge; можно задать `PLAYWRIGHT_CHANNEL=chrome`.
- `test:telegram`: пять launch hash с настоящим SDK и синтетическими данными.
- `check-build.mjs`: production в подпапке `/rakurs-demo/`, ресурсы, покупка и восстановление доступа.
- Для проверки публичной версии задайте `DEMO_URL=https://miroslavtitoo.github.io/rakurs-demo/`.
- Снимки: `tmp/design-v5/`. Превью и ZIP-пакеты: `output/`.

Сборка `dist/` статическая, ресурсы относительные, маршрутизация через hash. Другой HTTPS-хостинг также подходит. В BotFather нужно указать URL сайта, сам код туда не загружается.

## Данные и перенос из предыдущей версии

Хранение локально в браузере: `rakurs:aiPurchases`, `rakurs:favorites`, `rakurs:marketOnboardingSeen`. На другом устройстве состояние отдельное. Купленные основные материалы v4 (`rakurs:purchases`, `read-<eventId>`) открывают соответствующий AI-прогноз. Остальные старые данные не удаляются. Старые ссылки на разборы перенаправлены к матчу, удалённые разделы — к каталогу.

Для чистого показа используйте приватное окно. Новый вход покажет сторис. Повторный просмотр доступен без сброса данных.

## Сценарий показа — 2 минуты

1. Пройти четыре сторис.
2. В первой карточке увидеть прогноз, вероятность и цену. Нажать «Почему?».
3. Купить в демо — откроется полный прогноз с условиями и аргументами.
4. Открыть «Мои прогнозы», перезагрузить — доступ сохранён.
5. В «Результатах» показать удачные и неудачные записи.

## Контекст разработки

- `AGENTS.md`, `PROJECT_CONTEXT.md`, `DESIGN.md`, `STATUS.md` — актуальные решения и история.
- `src/MarketApp.jsx`, `src/market.css`, `src/marketData.js` — текущая редакция.
- Компоненты старого приложения v2–v4 сохранены в исходниках и Git, но не импортируются в новую сборку.
- PDF, `Refs/`, временные файлы, ZIP и секреты не публикуются в репозиторий.

Это демонстрация интерфейса: команды, оценки, прогнозы и результаты вымышлены, AI отвечает готовыми текстами, реальные платежи и внешние данные не подключены. Доступ к платному тексту здесь локальный. Backend, модель, платежи и приложения для магазинов — следующий этап. Проверки браузера и SDK не заменяют проверку Telegram на физических iOS/Android.
